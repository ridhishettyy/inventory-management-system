# Inventory & Operations Management System

A full-stack web application built using Django for managing inventory, tracking orders, monitoring stock levels, and visualizing operational insights through interactive dashboards.

## Features

- Product inventory management
- Order management system
- Real-time stock tracking
- Low-stock alerts using reorder point logic
- Interactive analytics dashboard with charts
- Search and filtering functionality
- Responsive and user-friendly interface
- CRUD operations for products and orders

## Tech Stack

- Backend: Django, Python
- Frontend: HTML, Tailwind CSS
- Database: SQLite
- Charts & Analytics: Chart.js
